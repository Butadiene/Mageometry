# 基礎理論：沿磁場電流と磁場の横断面異方性

[ドキュメント一覧](README.md) · [English](fac_anisotropy_theory.md)
· [横断面幾何の API](transverse_geometry.md) · [日本語 GUI ガイド](gui_ja.md)

本書は [英語版の基礎理論](fac_anisotropy_theory.md) の日本語訳です。
節番号、数式、記号、引用文献の対応を保ちます。実装との対応を確認するときは
英語版を基準としてください。

本書は、沿磁場電流（field-aligned current、FAC）と磁場の横断面異方性について、
本プロジェクトが用いる記号、方程式、仮定、実装を、外部文書を必要とせずに定義します。
数値変数、API キー、ビューアの項目名では **β_g** と **δ_g** に `beta_g` と
`delta_g` を用います。添字 g は幾何学的なせん断をプラズマのベータ値と区別します。

以下の数学的な定義・恒等式と、第7節の R1/R2 に関する解釈・実験案は区別します。
後者は検証すべき仮説です。

既存研究との対応は該当する数式の近くに示し、第8節に参照した版を明記します。
`beta_g`、`delta_g` という成分名と規格化診断量 η は本リポジトリの規約であり、
引用論文がこれらの名称を用いているという意味ではありません。

## 1. 基底、微分、電流の規約

B = |**B**| > 0、**T** = **B**/B とし、弧長 s は **T** の向きに増加するとします。
κ = |∂_s **T**| > 0 の場所では、フレネ主法線を **n** = ∂_s **T**/κ、
従法線を **b** = **T** × **n** と定義します。小文字の **b** は従法線であり、
磁場ではありません。方向微分は ∂_n = **n**·∇、∂_b = **b**·∇、
∂_s = **T**·∇ です。

変位電流を無視した静磁場・準静的なアンペールの関係 μ₀**J** = ∇×**B** を用い、
j_∥ = **J**·**T** とします。電流は次のように分解できます。

$$
\mu_0\mathbf J =
B\left[(\partial_n\mathbf T)\cdot\mathbf b
       +(\partial_b\mathbf n)\cdot\mathbf T\right]\mathbf T
+ (\partial_b B)\mathbf n
+ (B\kappa-\partial_n B)\mathbf b.
$$

磁場方向の横断面勾配の成分を次で定義します。

$$
M=\begin{pmatrix}a&q\\p&d\end{pmatrix},\qquad
a=\mathbf n\cdot\partial_n\mathbf T,\quad
q=\mathbf n\cdot\partial_b\mathbf T,\quad
p=\mathbf b\cdot\partial_n\mathbf T,\quad
d=\mathbf b\cdot\partial_b\mathbf T.
$$

行は出力成分 (n, b)、列は微分方向 (n, b) を表します。
**n**·**T** = 0 を微分すると (∂_b **n**)·**T** = −q なので、

$$
\alpha=p-q=\frac{\mu_0j_\parallel}{B},\qquad
\mathcal D=B\left[(\partial_n\mathbf T)\cdot\mathbf b
                  -(\partial_b\mathbf n)\cdot\mathbf T\right]
           =B(p+q).
$$

単位変換前の沿磁場電流の二つの項は **Bp** と **−Bq** です。
和は μ₀j_∥、差は **𝒟** になります。𝒟 は符号付きせん断診断量であり、
別の電流成分ではありません。

この α は [Tassev and Savcheva (2019) の式 (80)–(81)][tassev-savcheva] の
一般化された force-free パラメータです。その定義自体は force-free な磁場を仮定しません。

## 2. 標準記号と実装の対応

| 記号 | 定義 | API キー・実装 |
| --- | --- | --- |
| μ₀j_∥ | **T**·curl(**B**) = Bα | `fac`（直交座標の微分）、`mu0J_T`（従来のフレネ再構成） |
| α | p−q = μ₀j_∥/B | `alpha` |
| β_g | p+q = 𝒟/B | `beta_g` |
| δ_g | a−d | `delta_g` |
| Γ | √(β_g²+δ_g²) | `gamma`、表示名は `Gamma` |
| θ | a+d = tr M = ∇·**T** | `field_line_transverse_decomposition` 各分岐の `trace`。単独の幾何 API の出力には含まない |
| 𝒟 | Bβ_g | 従来の `B_twist_diff` は基底の微分から推定 |
| ω_c | sgn(α)√max(α²−Γ²,0)/2 | `omega_c` |
| η | (α²−Γ²)/(α²+Γ²) | `eta` |
| A | Γ/\|α\|、α ≠ 0 | `gamma_over_abs_alpha`、表示名は `Gamma/\|alpha\|` |
| ψ_S | ½ atan2(β_g, δ_g)、π を法とする | ひずみの主軸角。Γ = 0 では未定義 |

各変化率と κ の単位は長さの逆数です。𝒟 は磁場/長さ、η と A は無次元、
ψ_S は角度です。いずれも局所的な空間診断量であり、時間変化率ではありません。

q は行列要素 **n**·∂_b **T** だけを表します。有限差分の引数 `delta` は刻み幅 h
であり、δ_g とは無関係です。画面上の ASCII 表記 `beta_g`、`delta_g`、`Gamma`、
`omega_c`、`eta` は数式中の β_g、δ_g、Γ、ω_c、η に対応します。

`field_line_transverse_geometry` は `alpha`、`beta_g`、`delta_g`、`gamma`、
`gamma_over_abs_alpha`、`omega_c`、`eta`、`curvature` の8項目を返します。数値実装、ビューア・CLI の入力、
色範囲のキーも同じ診断名を用います。
`B_twist_diff/B` と磁場の一次勾配から求める `beta_g` は、基底が有効なら同じ定義に
収束しますが、有限の刻み幅では一致しない場合があります。
ビューアの電流換算は、電流と同じ次元を持つ 𝒟 にも適用されます。
電流密度単位で表示するときのラベルは `D / mu0` です。

## 3. 回転、ひずみ、基底の役割

横断面勾配は次のように分解できます。

$$
M=\frac\theta2 I
+\frac12\begin{pmatrix}\delta_g&\beta_g\\\beta_g&-\delta_g\end{pmatrix}
+\frac\alpha2\begin{pmatrix}0&-1\\1&0\end{pmatrix}.
$$

順に、等方的な拡大・縮小、対称かつトレースゼロのひずみ、回転を表します。
∇·**B** = 0 なら θ = −∂_s ln B です。磁束保存はトレースを制約しますが、
β_g や δ_g を決定しません。

[磁束管の概念図](transverse_decomposition_figure.md) は各係数を独立したモードとして、
3次元磁力線と対応する法平面断面で示します。円形断面の形が変わらない回転も、
オレンジ色の磁力線マーカーで確認できます。英語・日本語の SVG、PDF、PNG と、
作図の仮定・再生成スクリプトを用意しています。

この分解は [Selinger (2019) 第 II.1 節、式 (3)–(8)][selinger] が整理した
単位配向ベクトルの勾配分解の横断面部分です。配向ベクトルを **T** とすると、
同論文の splay は θ、twist は α、bend ベクトルは −κ**n**、
biaxial-splay テンソル Δ は第4節の S_⊥ に対応します。
同論文の ∂_i n_j という勾配の添字規約は、本書の出力成分を行とする規約の転置です。
これは幾何学的な対応であり、液晶の弾性定数や Oseen–Frank 自由エネルギーを
プラズマに割り当てるものではありません。特に biaxial splay 自体は、
saddle-splay の発散項全体（同論文の式 (20)）ではありません。

横断面内の分離方向 **e**(φ) = cosφ **n** + sinφ **b** に対し、局所角度変化率は

$$
\Omega(\phi)=\mathbf T\cdot[\mathbf e\times((\mathbf e\cdot\nabla)\mathbf T)]
=\frac\alpha2+\frac{\beta_g}2\cos2\phi-\frac{\delta_g}2\sin2\phi.
$$

したがって Ω_n = p、Ω_b = −q、Ω_n+Ω_b = α、Ω_n−Ω_b = β_g であり、
方位角平均は α/2、極値は (α±Γ)/2 です。
FAC は平均値を制約し、β_g と δ_g は方向による変動を記述します。
[方向別回転の概念図](directional_rotation_figure.md) は、これらの恒等式を、
ラベル付きの隣接磁力線、法平面内の符号付き矢印、Ω(φ) 曲線に対応させています。
編集可能な英語・日本語の SVG、PDF、PNG を用意しています。
方向別変化率とその方位角平均は
[Tassev and Savcheva (2019) の式 (83)–(86)][tassev-savcheva] と一致します。
∂_s **n** = −κ**T** + τ**b** とすると、フレネ基底で測った角度は
**dφ/ds = Ω(φ)−τ** を満たします。τ は磁力線のねじれ率です。
この補正なしに α/2 をフレネ基底での平均角度微分と同一視してはいけません。

[Liu et al. (2015) 付録 C.1、式 (C6)–(C9)][liu-et-al] は、幾何学的なリボンの
twist 密度を電流項と対称勾配項に分けています。同論文の c₃ を本書の記号で表すと、
無限小の分離の極限で

$$
\frac{c_3}{B}=\frac{\beta_g\cos2\phi-\delta_g\sin2\phi}{2},\qquad
\frac{d\mathcal T_g}{ds}=\frac{\Omega(\phi)}{2\pi}
=\frac{\alpha}{4\pi}+\frac{c_3}{2\pi B}
$$

です。したがって **e** = **n** では c₃/B = β_g/2 ですが、一般には分離方向に
依存します。同論文の対称テンソルは **B** を微分し、本書の S_⊥ は横断面への
射影後の磁場方向の微分を表します。この違いにより B の因子が必要になり、
c₃ と不変量 Γ を同一視できないことが分かります。

横断面基底を **n**′ = cosψ **n** + sinψ **b**、
**b**′ = −sinψ **n** + cosψ **b** と回転すると、

$$
\begin{pmatrix}\delta_g'\\\beta_g'\end{pmatrix}
=\begin{pmatrix}\cos2\psi&\sin2\psi\\-\sin2\psi&\cos2\psi\end{pmatrix}
\begin{pmatrix}\delta_g\\\beta_g\end{pmatrix}.
$$

Γ はこの変換で不変です。十分に解像されたフレネ基底では、β_g は曲率主法線を
基準とする意味のある成分ですが、異方性全体を測る量ではありません。
伸長の主軸方向は δ_g = Γ cos2ψ_S、β_g = Γ sin2ψ_S を満たします。
β_g の変化は、Γ の変化でも主軸の回転でも生じます。
Γ は M の対称部分の固有値差に等しく、
[Tassev and Savcheva (2019) 第 IV.5 節][tassev-savcheva] の
symmetrized squeeze rate に対応します。

余分な回転を加えない横断面基底で局所係数を固定すると、固有値は

$$
\lambda_\pm=\frac\theta2\pm\frac12\sqrt{\Gamma^2-\alpha^2}.
$$

符号を付けた虚部から ω_c が得られます
（[Tassev and Savcheva (2019) 式 (93)][tassev-savcheva]）。
同論文の式 (95) でも実固有値の場合は ω_c = 0 とします。
最小回転の法平面基底については同論文の第 III.3 節を参照してください。

等方的な拡大・縮小を除くと、η > 0 は局所的な回転、η < 0 は異方的な伸長、
η = 0 は単純せん断を含む両者の境界を表します。これだけで有限距離での巻き付きや
磁束ロープの存在は確定しません。実装では非巻き付き側の ω_c をゼロに拡張します。
α = Γ = 0 では η は未定義です。分母が微分誤差の大きさに近い場合、有限値の η も
信頼できないことがあります。

α ≠ 0 では、非負の比 A = Γ/|α| でも同じ局所的な比較ができ、
η = (1−A²)/(1+A²) が成り立ちます。A < 1 は回転側、A = 1 は境界、
A > 1 は異方的な伸長側です。A に上限はなく、α の符号は区別しません。
API は α = 0（Γ = 0 の場合も含む）、無効な差分、浮動小数点のオーバーフローでは NaN を返します。
分母に人工的な下限は入れません。小さい有限の α では、比が非常に大きくなり、微分誤差に敏感です。
この局所的な比だけで、有限距離の巻き付きや FAC による起源を確定することはできません。

## 4. 一次勾配からの評価と有効性

G_ij = ∂B_i/∂x_j、P = I−**T****T**ᵀ として、

$$
L=\frac1BPGP,\qquad
S_\perp=\frac{L+L^T}{2}-\frac{\operatorname{tr}L}{2}P,\qquad
\Gamma=\sqrt{2\operatorname{tr}(S_\perp^2)}.
$$

3次元直交座標テンソル L と、その2次元横断面表現 M は、元の磁場勾配 G とは
異なります。有効なフレネ基底では、

$$
\mathcal D=\mathbf b\cdot G\mathbf n+\mathbf n\cdot G\mathbf b,
\qquad B\delta_g=\mathbf n\cdot G\mathbf n-\mathbf b\cdot G\mathbf b.
$$

これらの式は **n** の微分を必要としません。実装では α を
**T**·curl(**B**)/B、Γ を S_⊥ から計算します。直線状の非ゼロ磁場でも
α と Γ は利用できますが、β_g と δ_g には解像された曲率主法線が必要です。
磁場の零点や無効な微分ステンシルでは NaN を返します。それ以外での厳密なゼロは
有効な結果です。未定義の幾何をゼロで置き換えてはいけません。
弱い曲率や小さい α²+Γ² には、刻み幅・格子の収束確認と、問題に応じた不確かさの
マスクを用いてください。モデルやシミュレーションから普遍的な物理ノイズ下限を
推定することはしません。

## 5. 解析的な比較と背景磁場の幾何

k > 0 に対し、代表的な局所横断面写像は次のとおりです。

| M（行ごとに表記） | α | β_g | δ_g | Γ | η |
| --- | --- | --- | --- | --- | --- |
| (0, −k; k, 0) | 2k | 0 | 0 | 0 | +1 |
| (0, 0; 2k, 0) | 2k | 2k | 0 | 2k | 0 |
| (0, k; k, 0) | 0 | 2k | 0 | 2k | −1 |
| (k, 0; 0, −k) | 0 | 0 | 2k | 2k | −1 |

最初の二例は α が等しくても隣接磁力線の幾何が異なります。
最後の例は 𝒟 = 0 ですが異方性はゼロではありません。
これらの局所例は曲率ゼロを必要としません。

電流のない中心双極子も基準になります。z 軸に沿った双極子を

$$
\mathbf B_{\rm dip}=\frac{m}{r^5}(3xz,\ 3yz,\ 2z^2-x^2-y^2),\qquad
r=\sqrt{x^2+y^2+z^2}>0,
$$

と書きます。m は磁場強度を定める非ゼロ定数です。
双極子軸からの余緯度を ϑ とすると、局所診断量は

$$
\alpha_{\rm dip}=0,\qquad \beta_{g,{\rm dip}}=0,\qquad
\Gamma_{\rm dip}=\frac{3|\cos\vartheta|\sin^2\vartheta}
{r(1+3\cos^2\vartheta)^{3/2}}.
$$

β_g の式はフレネ主法線が定義される場所に適用されます。
直線となる双極子軸上では Γ = 0 でも β_g は未定義です。

したがって Γ は FAC だけの効果ではありません。Γ の零点を除くと、電流のない
双極子でも η = −1 です。負の η だけでは電流による変形を示せません。
背景寄与の分解は、ノルムや比を取る前に、磁場勾配・テンソルに対して行う必要があります。

### 全磁場の基底での背景寄与

**B** = **B**₀ + **B**ᵣ に対し、背景 **B**₀（例：双極子）を指定し、
G₀ = ∇**B**₀、Gᵣ = G − G₀ とします。B = |**B**|、**T**、
P = I − **T****T**ᵀ と、定義できる場合の **n**、**b** は、すべて**全磁場**の
ものを共通して使います。k ∈ {0, r} に対して、

$$
L_k=\frac{P G_k P}{B},\qquad
S_k=\frac{L_k+L_k^{\mathsf T}}{2}
       -\frac{\operatorname{tr}L_k}{2}P,\qquad
\alpha_k=\frac{\mathbf T\cdot(\nabla\times\mathbf B_k)}{B},
$$

$$
\beta_{g,k}=\frac{\mathbf b\cdot G_k\mathbf n+
                         \mathbf n\cdot G_k\mathbf b}{B},\qquad
\delta_{g,k}=\frac{\mathbf n\cdot G_k\mathbf n-
                          \mathbf b\cdot G_k\mathbf b}{B},
$$

$$
\Gamma_k=\sqrt{2\operatorname{tr}(S_k^2)},\qquad
\eta_k=\frac{\alpha_k^2-\Gamma_k^2}{\alpha_k^2+\Gamma_k^2}.
$$

線形射影の後、第2–4節と同じスカラー量を構成します。
G = G₀ + Gᵣ、L = L₀ + Lᵣ、S = S₀ + Sᵣ、α = α₀ + αᵣ が成り立ちます。
共通のフレネ基底が存在すれば、β_g、δ_g、𝒟 = Bβ_g にも同じ加法性があります。
一方、せん断のノルムは

$$
\Gamma^2=\Gamma_0^2+\Gamma_r^2+
                  4\operatorname{tr}(S_0 S_r).
$$

交差項により増強も相殺も起こります。Γᵣ = Γ − Γ₀ も ηᵣ = η − η₀ も恒等式では
ありません。残差勾配がゼロなら Γᵣ = 0、αᵣ = 0 なので ηᵣ は**未定義**であり、
0 や −1 ではありません。電流のない背景は解析的には α₀ = 0 ですが、一般に S₀ は
非ゼロです。有限差分では小さい数値的な α₀ が残る場合があります。

実装は `geometry.field_line_transverse_decomposition(total, background, x, y, z)`
です。共通基底と、total・background・residual の G、L、S、横断面トレース、
発散、七つの診断量を公開します。両入力に同じ微分刻み幅を用います。
背景の無効なサンプルは背景・残差の分岐だけを無効にします。
規格化は |**B**₀| でなく B を使うため、背景の零点は許容されます。
全磁場の零点や無効な全磁場ステンシルでは、射影結果全体が無効になります。
全磁場のフレネ主法線を必要とするのは β_g と δ_g だけです。

各分岐の `gamma_over_abs_alpha` は、同じ全磁場基底で求めた A_k = Γ_k/|α_k| です。
全体の比から背景の比を引く量ではありません。電流のない背景では解析的に α₀ = 0 なので、
Γ₀ が非ゼロでも比は未定義ですが、有限差分誤差によって大きな有限値になることがあります。
残差勾配がゼロの場合も、その比は未定義です。

この分解は、**観測された横断面演算子にどの勾配が寄与するか**に答えます。
明示的な背景勾配を除いても、全磁場の基底と規格化には背景への依存が残ります。
一様磁場の追加は勾配寄与を持ちませんが、**T**、P、B、観測される Γ と η は
変え得ます。したがって、この分解は磁場追加に対するあらゆる幾何学的応答を
定量化するものではありません。

**B**ᵣ **自身**の方向と大きさで幾何を計算することは別の問いです。
その磁力線は異なる接続関係や零点を持ち得て、診断量を全磁場のものに加算できません。
寄与の η と形式的な ω_c,k = sign(α_k)√max(α_k²−Γ_k², 0)/2 は射影演算子を
記述する量であり、**B**ᵣ や **B**₀ の磁力線の巻き付き率ではありません。
第2–3節の実際の全磁場としての解釈を保持するのは total 分岐だけです。
指定した背景への寄与分解だけで特定の FAC 源を識別することもできません。
そのためには、電流源の分解を別途確立する必要があります。

`viz3d.transverse_contribution_view` は、共通の色範囲、しきい値、断面と
**全磁場**の磁力線追跡で三分岐を比較します。
対応するシミュレーションスナップショットを使う場合は、同じ座標・単位の背景を
明示的に指定し、その規約を確認せずに双極子を仮定しないでください。
[API の例](transverse_geometry.md#background-gradient-contributions) も参照してください。
モデルの電流源をオン・オフする操作は感度実験であり、新しい自己無撞着な平衡を
保証するものではありません。

## 6. 磁力線に沿った関係と有限距離写像

電流に基づく twist 積分は $\mathcal T_w=(4\pi)^{-1}\int\alpha\,ds$ です。
[Liu et al. (2015) 式 (7) と付録 C.1][liu-et-al] は、これが幾何学的な
リボンの twist と一致するには、基準軸に十分近く、対称勾配の寄与が無視できる
必要があると説明しています。一点での方位角平均は、指定した一対の磁力線の
巻き付き回数ではありません。

∇·**J** = 0、∇·**B** = 0 のもとで
**J** = (α/μ₀)**B** + **J**_⊥ と書くと、

$$
\partial_s\alpha=-\frac{\mu_0}{B}\nabla\cdot\mathbf J_\perp.
$$

これは沿磁場電流と垂直電流の空間的な接続を記述します。この式だけでは、時間的な
FAC の生成場所を特定したり、エネルギー変換を証明したりできません。
等方圧力による静的な力のつり合いでは **J**_⊥ = **B**×∇p/B² ですが、
その範囲外の圧力テンソルや慣性項は、それぞれの力のつり合いで扱う必要があります。
ここでの圧力 p は、上の行列要素 p とは別のものです。

余分な回転を持たない基底内の無限小横断面分離は
dF/ds = M(s)F、F(s₀) = I に従います。有限写像には M の順序を保った発展が
必要で、単なる ∫Γ ds では足りません。主軸方向の変化によって、それまでの伸長が
相殺されることもあります。磁場に垂直な断面と ∇·**B** = 0 に対して
|det F| = B(s₀)/B(s) です。フレネ基底で発展させるなら、基底の接続項
τ[[0, −1], [1, 0]] を M から差し引きます。
断面の伸長だけでは電流密度の増加は導けません。
横断面偏差の発展と、局所的な squeezing と有限距離の squashing の違いは
[Tassev and Savcheva (2019) 第 III–IV 節][tassev-savcheva] を参照してください。

## 7. R1/R2 の研究仮説と比較案

引用文献は単位ベクトル幾何や太陽磁場の診断を確立していますが、本書の磁気圏の
R1/R2 仮説を検証したものではありません。

Region 1（R1）と Region 2（R2）は、横断面診断量とは独立に分類した大規模 FAC
領域を指します。研究案では、それらの領域につながる磁束管を比較します。
上の定義から「R1 は回転優勢、R2 はせん断優勢」という規則は導かれません。
次の比較が考えられます。

- 地方時、高度、|α| をそろえ、(|α|, Γ)、η、β_g、ψ_S を比較する。
- α、Γ、∂_s α を追跡し、磁束管幾何の変化と沿磁場・垂直電流の接続を区別する。
  開いた磁力線は赤道通過を必須とせず、その境界まで扱う。
- 基底を固定して背景と電流源の寄与を分離する。
- IMF By や動圧を変化させ、Γ の強度変化と主軸の回転を区別する。
  半球間で基底と磁場方向の規約を統一する。
- 適切な MHD・観測データを用い、圧力勾配、**J**·**E**、磁気張力の仕事、
  伝播と幾何を比較する。静的な磁場モデルだけではエネルギー収支も因果関係も得られない。
- ベクトル磁場データから横断面勾配を制約する。FAC マップだけでは対称ひずみ成分を
  復元できない。一次元シートの仮定は、Γ ≈ |α| を発見するのでなく、あらかじめ
  課してしまう場合がある。

Γ は磁場**方向勾配**の異方性であり、粒子圧力の異方性や電流密度マップの形とは
異なります。提案した解釈の検証には、独立したモデル・観測の証拠が必要です。

現在のコードは、局所診断、明示的な背景勾配の寄与分解、ビューアでの比較を実装しています。
R1/R2 の分類、物理的な源の自動識別、ψ_S/A の出力、電流連続の診断、
有限距離写像 F の積分は実装していません。拡張する場合は、研究計画を検証済みの
機能として扱わず、追加の仮定と検証方法を明示してください。

この基礎理論は、提供された議論 **枝分かれ · FAC異方性の意味** をもとに整備しました。
本リポジトリで用いる定義と仮定は、上記にすべて記録しています。
